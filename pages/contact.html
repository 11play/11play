Security Notice

Never send private authentication information

11Play support does not need your Google password, third-party account password, mobile-wallet PIN, banking password, one-time password, recovery code or security code.

This rule applies to both email and Live Chat. Screenshots should be reviewed before sending so that passwords, OTPs, PINs, recovery codes and unnecessary personal information are not visible.

◈
Protected account operations

Authentication and Firestore Security

Protected 11Play profile features use Firebase Authentication to identify verified Google users and Cloud Firestore to store profile, email-association and protected Offer-administration records.

Firestore Security Rules restrict unauthorized database access and validate supported state changes. Protected profile and identity operations may use Firestore transactions or batches so related records remain consistent.

A mobile number successfully saved to the current profile is locked against ordinary user replacement or removal. The current system does not require that number to be globally unique across all 11Play accounts.

The current production profile and Offer administration architecture does not depend on deployed Firebase Cloud Functions for normal account operations.

Live Chat is separate from the 11Play Firestore account-data architecture. Chat delivery is handled through tawk.to and the current 11Play implementation does not create a separate Firestore chat-message collection.

Independent Third-Party Services

11Play provides structured access to independent third-party websites but does not own, host or control those platforms.

11Play does not accept third-party gaming deposits or process third-party gaming payments and withdrawals. Questions about an external account, deposit, transaction, gaming result or gaming withdrawal must be directed to the relevant external provider.

11Play support may assist with 11Play platform access, Google account and profile issues, mobile registration, Invite Your Friend sharing, the current 500 BDT promotional Offer, Live Chat access, privacy and related technical issues.

Support Knowledge Base

Frequently Asked Questions

Select a question to open its detailed answer. Select it again to close the answer.

01 What is 11Play?

11Play is a browser-based Smart Web Access and promotional platform. It organizes access to independent third-party websites and provides verified Google account, profile, Invite Your Friend, 500 BDT new-user Offer and tawk.to-powered Live Chat features.

External websites remain independently operated. 11Play does not control their accounts, transactions, offers, content or gaming outcomes.

02 Does 11Play operate the external gaming websites?

No. Third-party websites accessible through 11Play are owned and managed by their respective operators.

11Play does not manage their user accounts, deposits, gaming activity, payment decisions, gaming outcomes or withdrawals. Users must review the terms and support channels of each external provider.

03 Does 11Play process third-party deposits or gaming withdrawals?

No. 11Play does not accept gaming deposits or process payments and withdrawals for third-party gaming websites.

Any deposit, withdrawal, gaming balance or other financial transaction made directly with an external website remains between the user and that independent service.

04 What is the 500 BDT new-user Offer?

The current 11Play promotion provides an eligible new user with a 500 BDT Offer after the user follows the applicable Offer process and completes the required conditions.

The Offer is separate from third-party gaming deposits, gaming winnings or withdrawals. It is handled through the current 11Play Offer and support process.

Eligibility is not created automatically by simply opening the website or creating an 11Play profile.

05 How do I start the 500 BDT Offer?

Start by opening the 11Play Live Chat page before registering with the applicable target service.

Press Start Live Chat. The current 11Play chat is delivered through tawk.to and opens inside the 11Play website.

Obtain the target-site link and current instructions through the 11Play Offer process, then register through the supplied link.

Complete the applicable target-site requirements and return to 11Play Live Chat to request Offer review.

06 Does sharing 11Play automatically earn money?

No. The current Invite Your Friend feature is a normal sharing feature.

It shares the official 11Play website and promotional information but does not create a referral reward, personal reward balance or automatic payment.

Sharing 11Play does not by itself create eligibility for the 500 BDT new-user Offer.

07 Does 11Play still use referral codes?

No. The current Invite Your Friend feature does not assign a personal referral code or permanent referral link to the user.

Sharing uses the official 11Play website address: https://11play.github.io/11play/

The current share flow does not require a referral tracking query parameter.

08 Do I need to complete activity days for the 500 BDT Offer?

No. The current 500 BDT Offer does not use the previous seven-day or hourly activity-qualification model.

Users should follow the current Offer instructions provided through the Offer page and Live Chat rather than relying on old referral or activity requirements.

09 Does 11Play use Unique Web Device Binding for the current Offer?

No. The current account and 500 BDT Offer system does not require the previous Unique Web Device Binding qualification model.

11Play also does not claim to obtain an IMEI, Android serial number or another guaranteed immutable physical hardware identifier through normal website access.

10 Does 11Play have a referral wallet or withdrawal system?

No. The current 11Play account system does not provide referral reward balances, a user-facing promotional wallet or referral withdrawal requests.

The current promotional process centers on the 500 BDT new-user Offer and manual support workflow.

Financial transactions performed directly with an independent third-party website remain outside the 11Play account system.

11 What information does 11Play receive through Google Sign-In?

11Play may receive the Google profile name, verified email address, profile photo where available, sign-in provider information and Firebase Authentication identifier.

This limited information is used for account identity, authentication, profile operation, security and administration.

The current Live Chat module does not automatically send this protected 11Play profile information to tawk.to.

12 Does 11Play receive or store my Google password?

No. Google and Firebase Authentication manage the Google Sign-In process. 11Play does not receive or store the user's Google password.

Never send a Google password, recovery code, OTP or authentication code through email or Live Chat.

13 Why can I add a Bangladesh mobile number to my profile?

A valid Bangladesh mobile number may be stored as part of the user's 11Play profile.

The normalized format used by the current system is: +8801XXXXXXXXX.

The number may be used for profile operation, account administration and support where relevant.

14 Can two users save the same mobile number?

Yes. The current 11Play profile system does not require a mobile number to be globally unique across all user accounts.

Two different profiles may therefore contain the same valid Bangladesh mobile number where the current Firestore rules permit it.

15 Can I change my mobile number after saving it?

Normally no. After a valid mobile number is successfully saved to the current profile, the mobile is locked.

The ordinary user cannot normally replace, remove or reset the locked number through the profile interface.

If you believe incorrect information was saved, contact 11Play support and clearly explain the issue.

16 Does saving my mobile number prove SIM ownership?

No. Saving a mobile number in the 11Play profile does not by itself prove physical ownership of the SIM.

The current 11Play profile system does not represent this stored number as an SMS OTP-verified mobile identity.

A separate external service may have its own OTP verification requirements when the user registers directly with that service.

17 Can I see my Offer Paid status in my profile?

No. Offer Paid information is maintained as protected Admin-only administrative information.

The normal user profile does not display the protected Offer Paid record and ordinary users cannot create, edit or delete it.

The authorized administrator may mark the Offer Paid after the Offer has actually been provided.

18 Does 11Play sell users' personal information?

No. 11Play does not sell personal information to advertisers.

Limited information may be processed through services needed for Firebase Authentication, Cloud Firestore, analytics, GitHub Pages hosting, security and platform support.

When the user chooses to start Live Chat, chat messages and related chat-service information may be processed through tawk.to so that 11Play support can communicate with the user.

More information is available in the 11Play Privacy Policy .

19 Why is the 11Play page, account feature or Live Chat not loading correctly?

Loading or account problems may be caused by unstable internet, outdated cached files, disabled JavaScript, blocked Google authentication, expired account state, browser restrictions or a temporary GitHub Pages, Firebase, tawk.to or network-provider issue.

Refresh the page, verify the internet connection, switch between mobile data and Wi-Fi where appropriate, update the browser and sign in again if necessary.

If the Start Live Chat button opens but the chat itself cannot connect, verify that JavaScript and third-party network requests are not being blocked by the browser, private DNS, ad-blocking software or another network restriction.

Clearing site data may remove local favourites, browsing history, chat-session state or other local application preferences, but it does not automatically delete the protected profile stored in Cloud Firestore.

If the problem continues, include the connected account email where relevant, browser name, device type and a screenshot of the error when contacting support.

20 What should I include in a support request?

Include the issue category, connected Google account email where relevant, approximate date and time, device, operating system, browser and a clear description of what happened.

For profile or mobile problems, explain the exact profile field or action involved.

For the 500 BDT Offer, explain the current Offer step, whether you contacted Live Chat before registration and what issue occurred.

When using tawk.to Live Chat, provide only information reasonably required for the conversation. Do not send Google passwords, third-party passwords, wallet PINs, banking credentials, OTPs, recovery codes or security codes.

Include a screenshot only where useful. Remove passwords, OTPs, PINs, recovery codes and unnecessary personal information before sending it.

Standard email support requests normally aim for a response within 24–48 hours. Account-security, promotional Offer or other complex reviews may require additional time.
